# @kia-group/kia-community — KIA Community

**کیا گروه — جامعه** (KIA Community)

این دپارتمان مثل یک **پروژهٔ جدا** توسعه می‌یابد؛ پوشه‌های حوزه:

- `members`
- `discussions`
- `groups`
- `mentorship`
- `networking`

پوشش برنامه‌ریزی‌شده: اعضا، گفتگوها، گروه‌ها، منتورشیپ و شبکه‌سازی.

## قواعد معماری

- هر پوشهٔ خالی `README.md` مخصوص به خود را دارد (دامنهٔ آن حوزه).
- وابستگی مجاز: فقط `@kia-group/platform` (هستهٔ مشترک) و `@kia-group/shared`.
- **ممنوع** است هر import از/به دپارتمان دیگر (توسط ESLint مسدود شده است).
- نقطهٔ اتصال: `apps/api` (ثبت ماژول در `app.module.ts`) و `apps/group` (مسیرهای وب).

## وضعیت

فقط ساختار پوشه‌ها آماده است؛ کد این دپارتمان هنوز پیاده‌سازی نشده.
